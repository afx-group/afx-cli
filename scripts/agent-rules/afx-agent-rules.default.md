## Agent operating rules (apply to every AI tool and agent)

This block is generated by `afx-agent-rules-sync.sh` from one template; do not hand-edit it, change the template instead.
It is the neutral starter set shipped with the AFX CLI core. Put your own rules in `agent-rules/afx-agent-rules.template.md`
next to the script (that file wins when it exists) or point `AFX_AGENT_RULES_TEMPLATE` at it.

### Start every session with `afx brief`
- Run `afx brief` first: it prints which device you are on, whether this folder is an approved place to work, and which rules file to read.

### Git and where code lives
- The remote `origin/main` is the source of truth. Every working copy is a copy of it.
- Work on a branch in a worktree, never directly on `main`. Land work through a pull request.
- Never force-push, `git reset --hard`, `git clean`, or `rm -rf` a checkout. Stage explicit paths with `git add <file>`; never `git add -A` or `git add .`.
- Uncommitted changes you did not make belong to someone else: never restore, reset, clean or stash them; stop and report.
- Push your branch before you end a session. Do not leave work only on one machine.

### Honest reporting
- Report what you verified, not what you intended. Done means evidence: a passing check or a test run you saw.
- No fabricated data presented as real. Secrets never go in a commit; report the path, not the value.
